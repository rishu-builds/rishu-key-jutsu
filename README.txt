HOW TO RUN & PLAY:
------------------
1. Double-click "RishuKeyJutsu.exe" (or "KeyJutsu.exe").
2. The game will immediately launch in dedicated standalone App Mode with zero setup!
3. Alternatively, you can open "play.html" directly in any modern web browser.

GAME FEATURES (6 PLAYABLE SCREENS):
-----------------------------------
1. MAIN MENU:
   - Full arcade interface with dark keyboard backdrop.
   - Quick access to Campaign, Level Select, Speed Test, Stats & Settings.

2. CHOOSE YOUR PATH (100 LEVEL SELECT MAP):
   - 10 level cards per page with Unlock / Clear / Locked badges.
   - Target WPM progression (15 WPM to 148 WPM).
   - Red neon glow selection border with instant [START] battle button.

3. PROGRESS & STATS (TYPING DASHBOARD & HEATMAP):
   - Real-time tracking of Best WPM, Average WPM, Accuracy, and Practice Time.
   - Interactive QWERTY Keyboard Heatmap color-coded by accuracy:
     * 🟢 Strong (≥90%)
     * 🟡 Developing (80-89%)
     * 🔴 Weak (<80%)
   - Weak key detection with "PRACTICE WEAK KEYS" specialized combat mode!

4. TYPING SPEED TEST (STANDALONE PLACEMENT MODE):
   - 60-second timed challenge with live WPM & Accuracy meters.
   - Centered "TYPE THIS" target box with glowing character indicator.
   - Full interactive on-screen keyboard whose keys illuminate bright red in real time!
   - Calculates Ninja Rank (S, A, B, C, D) and unlocks tiers accordingly.

5 & 6. COMBAT VIEWPORTS (11 ATMOSPHERIC ARENAS):
   - Martial arts stickman fighting action: Jabs, Punches, Kicks, Uppercuts, Finishers!
   - Target words float directly above enemy heads!
   - Authentic trailer hit audio sounds played on every keystroke.
   - Combos, camera shakes, sparks, and 7-tier Ninja Ranks (F to S Grandmaster).

CONTROLS:
---------
- Type letters on your physical keyboard to strike opponents.
- Typos stagger your ninja and open you up to counter-attacks!
- ESC: Pause game or return to menu.
- Space: Type spaces in sentences and words.
